  1. 下载接入程序
    Windows x64Linux x64Linux ARM64

    下载入口优先使用服务器托管文件，否则转到最新 GitHub Release。需要包含临时 VPN 功能的发布版本。

  2. 下载配置，放在程序旁边
    查看配置
  3. 以管理员 / root 权限运行

    Windows：在管理员 PowerShell 中运行

    .\opennofrp-vpn-windows-amd64.exe -config .\opennofrp-vpn.json

    Linux：需安装 iproute2，并允许使用 /dev/net/tun。根据架构替换文件名。

    chmod +x opennofrp-vpn-linux-amd64
sudo ./opennofrp-vpn-linux-amd64 -config ./opennofrp-vpn.json
  4. 用地址和原端口访问服务

    例如，目标机器的 127.0.0.1:8080 对应 http://10.203.0.1:8080。支持 TCP 和 UDP；按 Ctrl+C 断开。

创建临时接入

选择一台在线内网机器，授权访问它的 127.0.0.1 上全部 TCP / UDP 端口。同一凭据同时允许一个接入程序连接。

启动时将别名写入接入设备的 hosts，指向 10.203.0.1，正常断开时清理。例如 http://local:8080。最多 8 个，逗号分隔；留空不修改 hosts。

连接程序只添加到 10.203.0.1 的单地址路由，不设置默认网关或 DNS。若该地址已有专用路由，程序会拒绝连接。一次连接一台机器。
